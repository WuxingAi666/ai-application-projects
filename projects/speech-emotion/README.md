# 中文语音情感分析系统

围绕中文短语音的情感分析，搭建录音上传、语音转写、声学与文本语义分析、结果对比和历史管理流程。重点实践语音模型、大模型 API 与前后端应用的集成。

**状态：** 应用原型 · 评测待完善。**材料依据：** 源码核对。

## 实际实现

- **双通道分析：** 接入声学分析模块与 faster-whisper 转写，调用 DeepSeek 输出六类情感分布、判断说明和关键短语。
- **决策与展示：** 采用按质量标记与置信度规则加权的 Late Fusion；Vue 3 / ECharts 展示声学、语义及融合结果，配套波形、梅尔频谱与语音反馈。
- **训练与服务：** 基于本地 1,200 条六类样本编写冻结 HuBERT 特征的分类头训练流程；FastAPI 配合 SQLite 保存分析记录，实现模型按需加载与失败兜底。

## 设计、取舍与边界

- **为什么结合声音与文本：** 声学通道关注声音表达，语义通道分析转写内容；统一六类输出后在决策层融合，并保留各通道结果供对照。
- **如何组织应用链路：** 音频统一为 16 kHz 单声道，重模型延迟加载并使用加载锁；接口层、模型层、服务层和数据层分工，前端管理录音与分析状态。
- **当前研发重点：** 当前 HuBERT 推理尚未加载已保存的分类头权重；需补齐训练与推理接入、独立评测及单通道对照，暂不报告系统准确率。

毕业设计初版。训练为冻结 HuBERT 特征后训练分类头；默认融合是规则驱动的 Late Fusion，算法效果仍需独立验证。

## 目录与运行

保留原项目的 Python 后端、Vue 前端及训练脚本，未重写模型算法。移除了训练集、音频、历史数据库、模型权重、密钥与运行日志。

Windows 本地预览（建议独立 Python 3.11 环境，Node.js 22.12+）：

```powershell
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
Copy-Item .env.example .env
# 私下填写 DeepSeek 密钥
.venv\Scripts\python run.py --host 127.0.0.1 --port 8000
```

另一终端：

```powershell
cd frontend
npm ci
npm run dev -- --host 127.0.0.1
```

打开 http://127.0.0.1:5173 ，API 文档为 http://127.0.0.1:8000/docs 。首次使用模型需要联网下载，失败时可能进入兜底分支，不能把兜底输出当作已训练模型效果。原启动脚本包含 Windows DLL 处理，跨平台部署需另行适配。
