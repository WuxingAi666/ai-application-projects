# 果蔬成熟度识别与语音采摘辅助

围绕果蔬成熟度初步判断，收集并整理成熟、半成熟、未成熟三类样本，训练视觉模型，并将识别结果连接语音助手，提供结果播报与采摘参考。

**状态：** 项目经历 · 暂不提供源码。**材料依据：** 本人经历说明。

## 实际实现

- **数据与训练：** 使用 YOLOv8 开展成熟度识别模型训练，积累样本准备与模型应用经验。
- **多种输入：** 结合 OpenCV 处理本地图片、视频上传及电脑摄像头在线识别。
- **交互反馈：** 接入 API 语音助手播报结果、给出采摘建议，串联视觉识别与使用反馈。
