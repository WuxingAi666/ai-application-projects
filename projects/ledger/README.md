# P6 · 仵星的记账本

从个人记账与发薪周期预算需求出发，通过 AI 辅助开发构建零依赖单文件应用，并在 GitHub Pages 部署。持续使用中逐步完善业务规则、数据兼容与交互。

**状态：** 已上线 · 本人持续使用。**材料依据：** 线上与源码核对。

## 实际实现

- **业务规则：** 日常 / 大额 / 固定支出、自定义周期分组、预算与储蓄目标、待办完成关联记账。
- **输入与统计：** 快捷模板、浏览器语音识别加规则解析、筛选查询，以及原生 SVG 分类占比和收支图表。
- **持久化与迭代：** localStorage 分模块保存，提供 JSON / CSV 与快照入口；Git 记录保留金额类型、固定支出同步和日均统计等迭代。

## 设计、取舍与边界

- **从使用中发现问题：** 金额字符串参与求和曾造成总额异常，因此同时处理输入转换、核算与旧字段类型迁移。
- **数据生命周期：** 删除周期分组时保留手动记录，清理相应自动固定支出；当前继续完善备份结构、月末扣款日和跨周期核算。

数据保存在当前浏览器，不提供云同步。核心记账可本地运行；语音识别依浏览器支持。

## 目录与运行

本目录的 `index.html` 是本人持续使用的 v3.1 源码快照，无 npm 依赖。

```powershell
python -m http.server 8940 --bind 127.0.0.1
```

打开 http://127.0.0.1:8940 ，数据保存在该来源的浏览器 localStorage 中。更换协议、域名或端口会使用另一份存储；迁移前先导出 JSON。
