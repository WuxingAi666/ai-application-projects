# BOSS 求职辅助与本地监控工具

围绕个人求职中的职位筛选、重复操作与消息回复，采用 Tampermonkey 浏览器脚本连接 DeepSeek，并以本地 FastAPI 服务记录操作事件、展示统计与运行反馈。

**状态：** 源码公开 · 个人技术实践。**材料依据：** 脚本与公开后端核对。

## 实际实现

- **浏览器交互：** 集中维护多组候选选择器，处理职位包含 / 排除筛选、滚动翻页、焦点与输入事件；提供手动启停和运行日志。
- **模型调用：** 使用最近八条聊天消息作为上下文调用 DeepSeek 生成回复；招呼语使用用户预设内容，配置通过 GM 存储保留。
- **本地监控：** FastAPI 接收事件，SQLAlchemy / SQLite 保存记录与每日计数，SSE 向看板推送更新，并提供本地简历图片接口。

## 设计、取舍与边界

- **方案怎样演变：** 最初尝试程序启动浏览器并由本人登录，但出现空白页、未完成该方案；最终改为在已登录浏览器内运行用户脚本。空白页根因尚未确定。
- **页面定位怎样处理：** 针对元素抓取不准，集中配置候选选择器并依次尝试，兼容点击、焦点和输入事件。平台页面变化仍可能导致脚本失效。
- **如何理解统计结果：** 看板统计来自脚本上报的操作事件，不等于平台确认投递成功；尚需完善在途请求取消、会话一致性和发送确认。

仅展示个人技术实践。实际遇到过元素定位与平台拦截问题，尚未证明可靠解决；不宣称绕过检测或无人值守运行。

## 目录与运行

- 用户脚本：`BOSS助手.user.js`，导入 Tampermonkey 后在本人已登录的浏览器内配置和手动启用。
- 本地服务：`app.py`，SQLite 操作事件记录和 SSE 看板。`dashboard.html` 为监控界面。
- 本整理版已清空脚本内原有默认密钥；密钥应由使用者在本机配置，不提交仓库。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

服务绑定本机 127.0.0.1:8899。只用于个人本地技术实践，未设计公开鉴权与公网部署。运行前按脚本面板配置模型与本地服务；按原项目要求自行准备简历图片，不发布个人简历文件。

### 与旧介绍的校正

元素定位采用候选选择器回退，未确认实现 Shadow DOM 遍历、随机等待、熔断或人工审核。平台拦截问题未被可靠解决。`apply` / `apply_start` 事件计数不等于招聘平台确认投递成功。首次方案中的浏览器空白页根因未查明。
