【为什么用 Embedding 与 FAISS】
Embedding 把问题和文档表示为语义向量，FAISS 在这些向量中召回近邻文本。项目把查询和文档向量归一化，用平方 L2 距离换算余弦相似度。该相似度只反映语义接近程度，不是答案正确率或真实性百分比。

【上下文、持久化与追问】
重叠分块用于减少边界切断上下文。索引指纹包含知识文件、Embedding 模型与切分配置，变化后启动时构建新版本。索引使用 FAISS 二进制和 JSON 文档持久化，不反序列化任意 pickle。多轮提问先结合最近对话补全指代，再进行语义召回，避免“这个项目”失去主题。

【安全、隐私与局限】
浏览器只访问后端，不持有模型密钥。后端配置 CORS、单 IP 与全局调用额度、并发限制、输入输出上限；管理接口单独鉴权。知识库只含公开内容。当前 Embedding 和生成使用外部 API，不能称为全离线私有化推理。规模为低流量个人展示，未宣称分布式高并发能力。没有资料支撑的问题应明确说明，不编造。
