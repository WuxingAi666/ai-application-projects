## 运行与配置

各项目分别创建独立环境，按各目录 README 运行。GitHub Pages 仅能托管静态页面；RAG API 需单独部署并配置 HTTPS 地址。当前公网问答尚未接入。所有密钥通过本机或服务器配置，仓库不含 .env、访客数据、音频、训练集、模型权重和企业内部材料。

原项目缺陷和未完成项在各目录明确记录；本次整理不等同于所有算法已完成验证或所有项目已生产上线。BOSS 目录沿用原项目 LICENSE，其他目录未单独授予开源许可，源码公开用于作品展示。
